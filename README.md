# Venta de Electrodomésticos - Backend PHP

Backend en PHP + MySQL para gestión de categorías, productos, clientes y ventas.

## Requisitos
- XAMPP (Apache y MySQL)
- PHP 8+
- MySQL/MariaDB

## Instalación
1. Clona este repositorio dentro de `C:\\xampp\\htdocs\\electrodomesticos`.
2. Enciende Apache y MySQL en XAMPP.
3. Importa `sql/venta_electrodomesticos.sql` en phpMyAdmin.
4. Abre `http://localhost/electrodomesticos/`.

## Endpoints
- `GET api/productos.php`
- `GET api/categorias.php`
- `GET api/clientes.php`
- `GET api/ventas.php`
- `GET api/dashboard.php`
- `POST api/login.php`
